# 🔮 Archaon OS

> Chaos is not a bug. Chaos is a feature.

Archaon OS is an Arch Linux-based operating system focused on freedom, experimentation, and unapologetic customization.

**Current Release: 1.0.0 "Chaotic Crow" 🐦‍⬛**

---

# 🚧 Development Status

Archaon OS is currently in **VERY early development**.

### What currently exists

- Project concept and roadmap
- Branding and identity
- Default dotfiles and configs
- Basic ISO build profile
- aon package manager
- Wiki documentation

### What does NOT currently exist

- Stable releases
- Production-ready installer
- Public package repositories
- Official support channels

---

# 💿 Installer ISO

An **ULTRA WIP installer ISO** is planned for release soon.

The first public ISO will be intended primarily for testing and experimentation.

**Estimated availability:** Next few weeks to months.

---

# 🧪 Early Adopter Warning

If you choose to test early Archaon builds expect:

- Bugs
- Missing features
- Incomplete documentation
- Rapid changes between releases

Test on virtual machines or spare hardware only.

# Features

- Arch Linux base
- Rolling release model
- Hyprland desktop environment
- SDDM display manager
- Modern Wayland-first workflow
- Custom Archaon branding
- Privacy hardened out of the box
- aon package manager
